# 検証用の学習セット

新しい機能を足したときに、いつも同じ条件で動きを確かめるための学習セットです。
どれも「まとめて貼り付け」で、そのまま学習セットにできます。

## 使い方

1. アプリで「＋ 新しいセット」を開き、タイトルに下の表の「タイトル」を入れる
2. ファイルを VS Code（またはメモ帳）で開き、全部選んでコピーする（Ctrl+A → Ctrl+C）
3. 「まとめて貼り付け」を押して貼り付け、区切りは「タブ」のまま「◯枚を追加する」→「作成する」

ファイルの中身が想定どおりに読めるかは、`src/lib/testSets.test.ts` が `npm run check` のたびに確かめています。
ファイルを書き換えたら、このテストの枚数も合わせて直してください。

| --------------------------- | ------------------ | ---- | ----------------------------------------------------------------------------------------------------------------------- |

| `03-korean-verbs-20.tsv`    | 検証03 韓国語動詞  | 20   | ふだんの使い方。どのモードも通しで遊べる                                                                                |
| `04-duplicate-answers.tsv`  | 検証04 同じ答え    | 7    | 答えが3種類しかないので、4択は3つの選択肢になる（同じ選択肢が並ばない）。逆向きなら4つ                                  |

## 05「ゆれ」：入力モードで打つものと、今の判定

今の判定は「完全一致」です（前後の空白と、正解の中の改行だけは気にしない）。
「ゆるい判定」を作ったら、この表の「今」の列がどう変わったかを確かめます。

| 問題                   | 正解           | 打つもの                 | 今     |
| ---------------------- | -------------- | ------------------------ | ------ |
| 1 + 1                  | 2              | `２`（全角）             | 不正解 |
| 日本の首都             | 東京           | `　東京　`（前後に空白） | 正解   |
| 英語で：りんご         | apple          | `Apple`                  | 不正解 |
| 英語で：アイスクリーム | ice cream      | `ice  cream`（空白2つ）  | 不正解 |
| カタカナで：computer   | コンピューター | `コンピュータ`           | 不正解 |
| ひらがなで：学校       | がっこう       | `ガッコウ`               | 不正解 |
| 記号の名前：-          | ハイフン       | `ハイフン`               | 正解   |
| 韓国語で：ありがとう   | 감사합니다     | `감사합니다`             | 正解   |
| 信号の色（上から2つ）  | 赤（改行）黄   | `赤 黄`                  | 正解   |
| I ( ) a student.       | am             | `AM`                     | 不正解 |

## ファイルを足すとき

- 名前は `番号-英語の短い名前.tsv`（日本語の名前にすると、`git status` で文字化けして見えるため）
- 1行が1枚、問題と答えはタブで区切る。セルの中に改行を入れたいときは `"…"` で囲む（`"` そのものは `""` と書く）
- わざと壊したファイルは 90 番台にする
- `src/lib/testSets.test.ts` の一覧と枚数に足す
